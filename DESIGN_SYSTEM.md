# Neon Cosmic Design System

## Color Palette
- Background: Deep cosmic navy #0a0a1a → #1a0033 → #0d001a gradient
- Card BG: rgba(15, 5, 40, 0.75) with backdrop-blur
- Primary Accent: Purple neon #8b5cf6 / #a855f7 / #c084fc
- Secondary Accent: Gold #ffd700 / #f59e0b (streak, daily mission border)
- Cyan Accent: #22d3ee (gem display, some borders)
- Text Primary: #ffffff
- Text Secondary: rgba(203, 213, 225, 0.8)
- Text Muted: rgba(148, 163, 184, 0.6)
- Success: #10b981
- XP Bar gradient: purple #7c3aed → cyan #22d3ee

## Card Styles
- Main cards: 2px solid purple border with intense glow (box-shadow: 0 0 20px rgba(139,92,246,0.5))
- Gold cards (daily mission): 2px solid gold border with gold glow
- Glass effect: backdrop-filter: blur(12px)
- Border radius: 16-20px

## Typography
- Display font: Luckiest Guy / Bangers (headings)
- Body font: Inter / Comic Neue
- Korean: Noto Sans KR

## Floating Elements
- Crystal/diamond shapes floating in background
- Subtle particle animation
- Purple nebula clouds in background

## Navigation Bar
- Bottom nav with 5 items: Home, Bible, Leaderboard, Store, Profile
- Active state: purple glow + icon highlight
- Background: dark with blur + top border purple glow

## Avatar
- Circular with animated purple neon ring border
- Level badge overlay
- 3D cartoon style character

## Progress Indicators
- Circular progress: purple gradient ring
- Linear progress: purple → cyan gradient bar
- XP bar: gold hexagon icon + progress bar
