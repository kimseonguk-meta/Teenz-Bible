# Teenz Bible Gem Store 실기기 테스트표

## 목적

이 표는 Gem Store가 실제 Galaxy PWA와 iPad 앱에서 구매, 차감, 보유, 장착, 앱 재시작 후 복원까지 정상 동작하는지 확인하기 위한 것이다. 테스트는 주 계정의 중요한 데이터가 손상되지 않도록 별도의 테스트 계정으로 수행한다.

## 사전 조건

테스트 계정으로 로그인하고 Gem Store에 들어간다. 테스트 시작 전 Gem 잔액, `Items owned`, 현재 장착 Theme/Reader/Frame/Pet을 화면 캡처한다. 테스트 중에는 브라우저 저장소를 삭제하거나 앱을 재설치하지 않는다.

## 핵심 테스트

| ID | 행동 | 기대 결과 | 실패 판정 |
|---|---|---|---|
| G1 | 가격이 낮은 미보유 Theme을 선택하고 구매 | 잔액이 정확히 가격만큼 감소하고 `Owned`로 바뀜 | 잔액 불일치, 구매 표시 없음 |
| G2 | G1의 Theme에서 Equip 선택 | `Equipped` 표시와 성공 안내가 나타남 | 버튼 무반응, 다른 Theme도 함께 장착 |
| G3 | Home 또는 성경 읽기 화면으로 이동 | 선택한 Theme의 실제 색상/배경이 적용됨 | Store 안에서만 바뀌고 다른 화면은 그대로 |
| G4 | Reader background를 구매하고 Equip | 성경 읽기 화면의 본문 배경이 바뀜 | 읽기 화면에 적용되지 않음 |
| G5 | Frame을 구매하고 Equip | Profile/해당 프레임 표시 영역에 적용됨 | Owned는 되지만 화면에 보이지 않음 |
| G6 | Pet을 구매하고 Equip | Pet이 해당 UI 영역에 표시되고 `Unequip`이 나타남 | 장착 표시만 있고 실제 화면 미반영 |
| G7 | 장착한 항목을 Unequip | 기본 Theme/Reader/Frame 또는 Pet 없음으로 복귀 | 해제 후 이전 아이템이 계속 적용 |
| G8 | 구매한 아이템을 다시 구매 시도 | 중복 구매가 막히고 Gem이 추가 차감되지 않음 | 같은 아이템을 중복 구매하거나 Gem 재차감 |
| G9 | 잔액이 가격보다 적은 상태에서 구매 시도 | 버튼이 비활성화되거나 `Not enough gems`가 표시되고 잔액 불변 | 음수 잔액·부분 차감·성공 표시 |
| G10 | Mystery Box를 열고 결과 확인 | Gem 차감 1회, 애니메이션 종료, 실제 item 또는 gem reward 지급 | 무한 로딩, 결과 없음, 잔액만 차감 |
| G11 | 구매·장착 직후 앱을 완전히 종료하고 재실행 | Owned와 Equipped 상태가 유지됨 | 재실행 후 소유·장착 정보 소실 |
| G12 | 같은 계정으로 다른 기기에서 로그인 | 제품 정책상 동기화 대상이면 동일 상태가 보임. local-only라면 문서에 명확히 표시 | 기기별 상태가 예고 없이 다름 |

## 실행 순서

먼저 Galaxy PWA에서 G1부터 G11까지 수행한다. 그 다음 동일한 테스트 계정으로 iPad 앱에서 G1, G2, G3, G4, G6, G9, G10, G11을 반복한다. 각 단계에서 잔액·Owned·Equipped 상태를 캡처한다. 구매 성공을 확인할 때는 화면의 알림만 믿지 말고 Gem 잔액과 앱 재시작 후 보유 상태를 함께 확인한다.

## 현재 코드 기준의 주의점

Gem 잔액은 `teensBible` localStorage의 `gems` 필드에서 읽고, 보유 목록은 `ownedItems`, 장착 상태는 Theme·Reader background·Frame·Pet별 상태로 관리된다. 따라서 앱 저장소를 지우면 데이터가 사라질 가능성이 있으므로 테스트 중 저장소 초기화는 금지한다. 구매·장착 성공 후에는 `teensBibleCriticalSync` 또는 `teensBibleDataChanged` 이벤트가 발생하는 흐름을 사용한다.

이 표에서 하나라도 실패하면 구매·콘텐츠 확장 작업을 중단하고, 먼저 해당 실패를 재현할 기기·앱 버전·계정·잔액·행동 순서를 기록한다.
