# Teenz Bible — iPad Final Smoke Test

이 체크리스트는 **새 Xcode Archive를 App Store Connect에 올리기 전**, 실제 iPad에서 약 20–30분 동안 수행하는 마지막 기능 확인 절차입니다. 순서를 바꾸지 않는 편이 좋습니다.

> **중요:** 아직 새 Archive를 만들기 전이라면, Mac의 프로젝트 폴더에서 먼저 `pnpm exec cap sync ios`를 실행한 후 Xcode에서 `App.xcworkspace`를 여세요. 이 단계가 최신 1.1.96 웹 번들을 새 iOS 앱 안에 넣습니다.

## 0. 준비물

| 준비물 | 준비 방법 | 용도 |
| --- | --- | --- |
| 실제 iPad | Wi‑Fi 연결, 충분한 배터리, Xcode에서 새 Release 후보를 설치한 상태 | iOS 네이티브 로그인·OTA·터치 테스트 |
| 테스트 계정 A | iPad에서 로그인할 Teenz Bible 계정 | Cheer를 보내는 계정 |
| 테스트 계정 B | Galaxy PWA 또는 다른 휴대폰/브라우저에서 로그인할 다른 Teenz Bible 계정 | Cheer를 받는 계정 |
| 새 사용자용 테스트 환경 | 가능하면 Safari/Chrome 시크릿 탭 또는 아직 로그인하지 않은 보조 기기 | 첫 온보딩과 Crew 생성/가입 테스트 |
| 화면 녹화 | iPad 제어 센터에서 화면 녹화 버튼을 추가 | 실패 시 재현 영상을 남김 |

계정 B는 이미 Cheer를 받은 계정이어도 괜찮지만, **새 Cheer와 24시간 제한을 동시에 확인하려면 최근 24시간 안에 계정 A가 Cheer를 보내지 않은 다른 계정**을 사용하세요. 기존에 사용했던 hajoon 계정이 제한에 걸릴 수 있으면 다른 테스트 계정을 쓰는 편이 빠릅니다.

## 1. 설치 및 기본 실행

1. Xcode에서 새 빌드를 iPad에 설치합니다. 설치가 끝난 뒤에는 USB 케이블을 분리해도 됩니다.
2. iPad 홈 화면에서 **Teenz Bible**을 직접 엽니다.
3. Home, Bible, Ranking, Store, Profile 탭을 차례로 한 번씩 누릅니다.

| 통과 기준 | 실패 기준 |
| --- | --- |
| 앱이 검은 화면·무한 로딩·강제 종료 없이 열리고, 다섯 탭 모두 전환됩니다. | 흰/검은 빈 화면, 멈춤, 앱 종료, 특정 탭을 눌렀을 때 반응 없음 |

## 2. Apple 로그인

1. 로그아웃 상태이거나 신규 프로필 상태에서 **Apple** 버튼을 누릅니다.
2. iPad의 Apple 로그인 시트가 열리는지 확인합니다.
3. 계속을 선택해 로그인 과정을 끝냅니다.
4. Teenz Bible로 돌아왔을 때 로그인한 사용자 이름/프로필이 보이는지 확인합니다.

> 이미 Apple 계정이 다른 Teenz Bible 계정에 연결되어 있다면, 오류 코드가 아니라 **Keep Using This Account / Choose Another** 선택지가 나타나야 합니다.

| 통과 기준 | 실패 기준 |
| --- | --- |
| Apple 시트가 열리고, 완료 후 앱으로 돌아와 로그인 상태가 유지됩니다. | 버튼 무반응, 시트가 닫힌 뒤 멈춤, 원시 Firebase 오류, 계속 로딩 |

## 3. Google 로그인

Apple 로그인과 같은 계정으로 연결하지 말고, 가능하면 로그아웃 후 Google 로그인만 별도로 확인합니다.

1. **Google** 버튼을 누릅니다.
2. Google 계정 선택 화면이 나타나는지 확인합니다.
3. 테스트 Google 계정을 고르고, Teenz Bible로 정상 복귀하는지 확인합니다.
4. 해당 Google 계정이 이미 다른 Teenz Bible 계정에 연결된 경우에는 영어 계정 충돌 선택지가 나오는지 확인합니다.

| 통과 기준 | 실패 기준 |
| --- | --- |
| 계정 선택 화면이 표시되고, 선택 후 앱으로 돌아와 로그인됩니다. | `Connecting to Google`에서 멈춤, 버튼 무반응, 웹 브라우저로 이탈한 뒤 앱에 복귀하지 못함 |

## 4. 새 사용자 온보딩 및 Crew 생성/가입

이 단계는 현재 iPad 계정을 초기화하지 않기 위해, **시크릿 탭의 PWA 또는 보조 기기**에서 수행하는 것을 권장합니다.

1. `https://teens-bible-94271.web.app`을 시크릿/비공개 창에서 엽니다.
2. 온보딩을 끝까지 진행하고, 필요한 초기 설정을 선택합니다.
3. Ranking 탭으로 가서 **Create Crew**를 누릅니다. Crew 이름 또는 초대 코드를 입력해 실제 생성이 완료되는지 확인합니다.
4. 다른 새 사용자 환경에서 **Join Crew**를 누르고, 생성된 초대 코드로 입장합니다.
5. Ranking 화면에서 `Viewing Crew` 선택기를 열고 방금 만든 Crew가 표시되는지 확인합니다.

| 통과 기준 | 실패 기준 |
| --- | --- |
| Create/Join 팝업이 중앙에 표시되고, 생성 또는 가입 후 실제 Crew가 Ranking에 나타납니다. | 버튼이 Profile로만 이동, 팝업이 화면 밖에 뜸, 가입/생성 후 데이터가 저장되지 않음, 권한 오류 노출 |

## 5. Ranking · Cheer · 수신함 · 콘페티

이 테스트는 **iPad의 계정 A**와 **Galaxy PWA 또는 다른 기기의 계정 B**를 함께 사용합니다.

1. iPad에서 계정 A로 로그인한 뒤 Ranking 탭으로 갑니다.
2. 계정 B의 Ranking 사용자 행을 누릅니다. 프로필 모달이 열리는지 봅니다.
3. 하단의 **Close**를 누르고 닫힐 때까지 확인합니다.
4. 다시 다른 사용자 행을 하나 더 누릅니다. 첫 번째 모달을 닫은 뒤에도 두 번째 행이 정상적으로 열려야 합니다.
5. 계정 B를 다시 열고, **Cheer**를 한 번 보냅니다. `Sent! [name] will see your encouragement.` 같은 성공 문구가 표시되어야 합니다.
6. 계정 B 기기에서 Teenz Bible을 열고 **Profile** 탭으로 이동합니다. Profile 헤더 아래에 `⚔️ ENCOURAGEMENTS` 카드, 보낸 사람 이름, `cheered for you · Keep growing!`, 상대 시간 표기가 나타나는지 봅니다.
7. 새 Cheer를 처음 확인한 순간 카드가 짧게 빛나고 카드 안에서 소량의 콘페티가 날리는지 확인합니다. 다시 Profile을 열 때마다 반복되면 안 됩니다.
8. iPad 계정 A에서 같은 계정 B에게 다시 Cheer를 보냅니다.

| 통과 기준 | 실패 기준 |
| --- | --- |
| 모달 Close와 여러 사용자 선택이 모두 동작하고, B의 Profile에 카드·콘페티가 표시됩니다. 같은 사람에게 두 번째 Cheer를 보낼 때에는 친절한 24시간 제한 메시지가 나옵니다. | 버튼 무반응, 모달 탈출 불가, 다른 행이 눌리지 않음, B에 카드 없음, 콘페티가 계속 반복됨, `401` 또는 Firebase 원문 오류 노출 |

## 6. Bible AI

1. iPad에서 **Bible AI**를 엽니다.
2. 좌측 상단의 `←` Back 버튼을 눌러 Home으로 돌아갑니다.
3. 다시 Bible AI를 열고, 입력창에 다음을 입력합니다: `What does John 3:16 mean?`
4. Send를 눌러 답변이 표시되는지, 하단 입력줄이 과도하게 높지 않은지 확인합니다.
5. 마이크 권한을 확인하려면 mic을 한 번 누릅니다. iPad 권한 시트가 나오면 허용한 뒤 짧게 말해 보고 텍스트가 입력되는지 확인합니다. 마이크 테스트는 선택 사항입니다.

| 통과 기준 | 실패 기준 |
| --- | --- |
| Back 버튼이 언제나 보이고 동작하며, 한 줄짜리 하단 입력창에서 메시지를 보내고 답변을 볼 수 있습니다. | Back 버튼 없음, 하단 패널이 화면 대부분을 차지함, Send 무반응, 원시 API/Firebase 오류 노출 |

## 7. 앱 재시작 및 OTA 안정성

1. iPad에서 Teenz Bible을 앱 전환 화면에서 완전히 쓸어 올려 종료합니다.
2. 약 10초 뒤 다시 엽니다.
3. Home → Ranking → Profile → Bible AI를 다시 빠르게 이동해 봅니다.
4. 한 번 더 완전히 종료한 뒤 재실행합니다.

| 통과 기준 | 실패 기준 |
| --- | --- |
| 재시작 뒤 앱이 정상적으로 열리고, 화면 전환·로그인 상태·Profile 응원함이 유지됩니다. | 첫 재시작 뒤 흰 화면, 반복 크래시, 로그인 풀림, 특정 탭 무한 로딩 |

| 재현 한 줄 | 예: `iPad / Google / 계정 선택 후 Connecting to Google에서 30초 멈춤`처럼 기기·동작·결과를 한 줄로 기록합니다. |

## 최종 판정

Apple 로그인, Google 로그인, Crew 흐름, Cheer 수신/제한, Bible AI, 두 번의 재시작이 모두 통과하면 **Archive 진행 가능**입니다. Xcode에서 `Version`과 `Build`를 다시 확인한 뒤, 다음 업로드는 현재 build 5보다 큰 **build 6**으로 올리세요.
