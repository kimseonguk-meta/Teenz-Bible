# 한국어 성경 전체 문맥 감사 최종본

## 검토 범위

한국어 성경 데이터는 66권, 16,427개 문단 레코드로 추출하여 장·절 또는 구역 제목 식별자와 함께 검사했다. 단순히 특정 단어가 있다는 이유로 성경의 사건 내용을 삭제하지 않고, **번역자의 말투가 저속하거나 인터넷식·모욕적으로 들리는지**를 별도로 판단하는 원칙을 적용했다.

성경 본문에 포함된 전쟁, 죽음, 심판, 노예, 성적 죄, 저주, 재앙 등의 내용은 성경이 다루는 사건 자체이므로 자동 삭제 대상이 아니다. 예를 들어 `살인`, `강간`, `간음`, `창녀`, `노예`, `재앙` 같은 단어는 문맥상 성경 사건을 정확히 설명하는 경우가 있어, 단어만 보고 번역 오류로 판정하지 않았다.

## 이번 단계에서 반영한 수정

원문 문맥을 직접 확인한 뒤, 명백한 인터넷식·저속·비하 표현만 최소 범위로 수정했다. **총 56건의 구절 표현을 50개 문단에서 수정**했으며, 앱 PWA asset, 저장소 루트 asset, native-ios 웹 사본, Xcode embedded public 사본에 동일하게 반영했다.

| 기존 표현 또는 문맥 | 수정 방향 |
|---|---|
| `구라죠` | `거짓말이죠` |
| `빵 터져서` | `웃음이 터져서` |
| `쩌리` | `보잘것없는 존재` |
| `개그 취급하시잖아요` | `우습게 여기시잖아요` |
| `쳐박아버렸음` | `바다 한가운데에 빠뜨렸음` |
| `한 놈도` | 문맥상 모두 사람을 가리키므로 `한 사람도` |
| `완전 쫄아서` | `몹시 두려워하여` |
| `꼴 보기 싫어져서` | `몹시 미워하여` |
| `이딴 소리` | `그런 말` |
| `쌩깐` 계열 | `무시한`, `모른 척한`, `속이고 떠난`, `저버린` 등 문맥별 표현 |
| `완전 빡빡하게` 계열 | `혹독하게`, `맹렬하게`, `맹렬하게 공격해` 등 문맥별 표현 |

문맥별 변경 전·후 전체 문장은 `korean-reviewed-changes-2026-08-20.md`에 기록했다. 따라서 나중에 특정 구절의 수정 이유를 다시 확인할 수 있다.

## 수정하지 않고 보류한 표현

`거임`, `했음`, `쟤네`, `걔네`, `완전`, `헛소리`, `튀어`, `놈`, `바보`, `염병` 등은 일부 문맥에서는 지나치게 가벼운 말투이지만, 다른 문맥에서는 성경 인물의 직접 발화, 동물의 움직임, 또는 성경 사건을 설명하는 일반 표현일 수 있다. 이들은 현재 단계에서 전체 일괄 치환하지 않았다.

특히 `쟤네`와 `걔네`는 저속한 욕설은 아니지만 문어체 성경 번역보다는 매우 구어적이다. `헛소리`와 `놈`은 인물의 모욕적 발화나 본문의 비난 어조를 전달하는 역할을 할 수 있으므로, 전체 문단을 보지 않고 `쓸데없는 말` 또는 `사람`으로 바꾸면 의미와 감정이 달라질 수 있다. 이 잔여 후보들은 `korean-remaining-context-audit-2026-08-20.md`에 문맥별로 모아 두었으며, 다음 편집 단계에서 장·절별로 별도 판단해야 한다.

## 검증 결과

수정 후 전체 데이터를 다시 장·절 레코드로 추출했으며, 총 레코드 수는 원본과 동일한 16,427개였다. 네 배포 사본의 SHA-256은 모두 동일하다. JavaScript 구문 검사도 통과했다. 이번 수정은 성경 레코드의 개수나 책·장 구조를 변경하지 않고 텍스트 표현만 변경했다.

현재 수정본은 **추가적인 사용자 확인 없이 바로 배포하지 않는다**. OTA ZIP을 만들 때에는 이 검증 결과와 manifest checksum을 다시 확인한 뒤, PWA와 iPad 앱에서 한국어 본문을 열어 대표 구절과 변경 구절을 실제로 확인해야 한다.
